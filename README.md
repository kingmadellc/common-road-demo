# Signals End · playable concept demo

[Play the eastbound journey](https://kingmadellc.github.io/common-road-demo/?v=0.7.1) · [Brand kit](https://kingmadellc.github.io/common-road-demo/brand/?v=3) · [Previous demo and save](https://kingmadellc.github.io/common-road-demo/v06/)

Escape account-controlled San Francisco with the Mercer family. Cross the Sierra, Nevada, Utah, Wyoming, Nebraska and Kansas to reach Signals End, a fictional analog refuge in the Missouri–Arkansas Ozarks. Fish, salvage, repair, evade the Collectors and earn a witness or deliver ceramic water filters. A guarded convoy leaves in five days; the reward is a paper deed and a home independent of a job.

Version 0.7.1 opens with a 96-second illustrated motion-graphics film: the city’s promise, its price, old machines, and a rumor of freedom. Brief captions replace the exposition cards. First visits start muted; Skip is always available, viewing is remembered on this browser, and Replay opening is available later. Reduced-motion and data-saver preferences bypass autoplay. Existing saves are preserved.

The journey connects eight playable chapters. The Journey menu shows your current objective, admission status and next drive; the whole trail is available underneath. Story moments turn Uncle Frank’s rumor into a letter, a reservation, a reunion and a key. Entry includes accepting the analog charter and storing digital belongings outside the Line.

Touch first, with controller and keyboard support. New v0.7 saves stay separate from v0.6. This is a browser playtest, not a native Apple release or a claim of human-tested fun.

Automated checks cover both full paths, normal-resource simulation wins, touch fishing, save continuity, actual portrait/landscape video playback, skipped/completed viewing history, blocked autoplay, offline replay, controller menu navigation and reduced motion. Build provenance is in build-info.json. The full source repository is private; this repository contains the public playable payload.
