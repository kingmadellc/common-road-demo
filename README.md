# The Last Affordable Place

[Play the game](https://kingmadellc.github.io/common-road-demo/)

A near-future road-trip satire about finding a life the next month can afford. Pack six slots in the van, choose your roads, take bounded jobs, and choose a new home.

Browser playtest 0.1.0: 17 encounters, eight cargo objects, branching routes and four endings. Touch supports portrait or landscape. Controller: D-pad/stick, south button to choose, east button to go back, Start to pause. Keyboard: arrows/Tab/Enter and Escape.

Your journey saves in this browser. Once the offline shell has installed, the game can reopen without a connection. No login, payments, live services, or external assets. The downloaded app is about 105 KB.

This repository contains the public browser assets, including JavaScript source. The larger planning and project history is maintained separately. The original illustration and all fictional story content are part of this prototype.

Physical Apple device performance, hardware controllers, and human fun are still being evaluated. This is not a signed native iOS release.
